# AGENTS.md — Работа с проектом «Кадр»

## Разработка

- Читать `spec.md` и текущий план перед работой. В 5.2.5 использовать `plan.md`, в 5.2.6 — также `plan-5.2.6.md`.
- Выполнять один этап за раз. Показывать созданные файлы, фактические команды и результаты проверки. Отмечать выполненные пункты плана только после успешного запуска.
- Создавать код и помогать с окружением. Если команда недоступна, дать пользователю точную команду для его ОС и дождаться фактического вывода.
- Не менять правила сервиса в `docs/`. Метаданные брать из источников, состав индекса — из проверенного `inventory.csv`.
- Из полных дубликатов индексировать только одну копию. Старую версию исключать до вычисления эмбеддингов. Проверять уникальность ID среди включённых файлов.
- Использовать E5 и ChromaDB с настройками из `spec.md`. Сохранять исходный текст фрагментов для чтения и цитирования.
- Реализовать поиск по произвольному вопросу. Не зашивать ответы, список источников или решения по имени проверочного сценария.
- Не выдумывать команды, логи, эмбеддинги, расстояния или результаты поиска. Ошибку исправлять и проверять повторным запуском.
- Перед поиском проверять актуальность сохранённого индекса. Изменение документов или настроек требует повторной индексации.

## Ответы по документам

В 5.2.5 команды `retrieve` и `ask` возвращают найденные фрагменты. Ответы с источниками добавляются в 5.2.6 после появления `rag-policy.md`.

Когда пользователь просит ответить на вопрос по сервису и `rag-policy.md` уже есть, сначала выполнить новый поиск для этого вопроса. Прочитать его фактический JSON, затем следовать правилам `rag-policy.md` и проверить ответ через `finalize`. Использовать только фрагменты текущего поиска, не заменять их памятью чата.
