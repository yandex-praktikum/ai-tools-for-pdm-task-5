# RAG-помощник сервиса «Кадр»

«Кадр» — сервис бронирования фотостудий. Помощник должен находить правила бронирования, доступа, работы с оборудованием и возврата оплаты.

В `docs/` лежат 12 исходных документов. Требования к проекту записаны в `spec.md`, последовательность работы — в `plan.md`, правила для ИИ — в `AGENTS.md`.

Откройте эту папку в приложении, где работаете с ИИ, и начните с первого пункта `plan.md`. Код проекта предстоит создать вместе с ИИ. Для работы нужны Python 3.13, интернет для первой загрузки библиотек и модели и около 3 ГБ свободного места.

В 5.2.5 вы соберёте поиск по документам. В 5.2.6 продолжите этот проект и добавите ответы с источниками.

Исходные документы разрешено использовать в базе знаний этого проекта.
