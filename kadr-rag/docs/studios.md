# Студии и стоимость бронирования

«Кадр» предоставляет фотостудии для съёмок по предварительной оплаченной брони. Условия действуют для всех трёх залов сервиса.

## Залы

«Свет» — зал с большими окнами площадью 60 м². В нём допускается до восьми участников, стоимость составляет 2400 рублей за час.

«Фон» — зал с бумажными фонами площадью 40 м². В нём допускается до шести участников, стоимость составляет 1800 рублей за час.

«Предмет» — зал для предметной съёмки площадью 25 м². В нём допускается до четырёх участников, стоимость составляет 1500 рублей за час.

## Продолжительность и расписание

Студии работают ежедневно с 08:00 до 22:00. Минимальная бронь — один час. После первого часа время добавляется блоками по 30 минут по половине часовой ставки выбранного зала.

Расписание свободных окон хранится в системе бронирования. Этот документ описывает общие условия и не показывает текущую доступность конкретного зала.
