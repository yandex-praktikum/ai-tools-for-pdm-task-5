# Создание и подтверждение брони

Бронь связывает выбранный зал, дату, время начала и окончания съёмки. Контактным лицом является клиент, который оформляет заказ.

## Выбор и оплата

После выбора времени сервис удерживает его за клиентом 20 минут. Для подтверждения нужна полная оплата. Если оплата не поступила за 20 минут, удержание снимается, а время снова становится доступным для бронирования.

Оплаченную бронь подтверждает письмо с номером заказа, названием зала, датой и временем. Сообщение об удержании времени без оплаты не является подтверждённой бронью.

## Изменение данных

Контактный телефон и состав участников можно изменить через поддержку до начала съёмки. Смена зала или времени оформляется по правилам переноса. Для любого обращения нужно указать номер заказа.
