# Обращения в поддержку

Поддержка помогает с подтверждёнными бронями, изменениями заказа и проверкой возврата. Обращение связано с номером заказа.

## Каналы и часы работы

Поддержка работает ежедневно с 08:00 до 22:00. Обратиться можно через чат в личном кабинете или по адресу support@kadr.example. Во время съёмки срочные вопросы решает администратор на месте.

## Что указать

Для обращения нужны номер заказа, дата съёмки и краткое описание вопроса. Не отправлять номер банковской карты, код подтверждения платежа или пароль. Для проверки возврата достаточно номера заказа.

Ответ по обращению приходит в течение двух часов в часы работы поддержки. Полученное вне этих часов обращение обрабатывается после открытия поддержки.
