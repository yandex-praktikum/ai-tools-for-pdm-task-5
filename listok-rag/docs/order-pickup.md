# Получение заказа в пункте самовывоза

Самовывоз доступен для заказов, которым при оформлении выбран пункт выдачи. Статус «собран» ещё не означает готовность к получению: клиент ждёт уведомления «готов к выдаче» с адресом и сроком хранения.

## Как получить заказ

Для выдачи нужен одноразовый код из карточки заказа. Сотрудник пункта сверяет код и число пакетов. Банковская карта не запрашивается, поскольку заказ уже оплачен. Скриншот прежнего кода не используется после выпуска нового: действителен последний код в карточке.

Клиент может передать действующий код доверенному получателю. Сотрудник не сообщает код тому, кто назвал только номер телефона. Если код потерян, поддержка помогает восстановить доступ через подтверждённый аккаунт, а не диктует код в публичном чате.

## Срок хранения

Заказ хранится до окончания выбранного интервала получения и ещё два часа после него, но не позже закрытия пункта. Приложение показывает конкретное время окончания хранения. Оператор ориентируется на это время и режим пункта, а не добавляет два часа к моменту обращения клиента.

Продление возможно только после подтверждения пункта выдачи. Поддержка не обещает хранение до следующего дня: продукты могут требовать условий, которые пункт обеспечивает только в пределах текущего периода. Если время истекло, оператор уточняет фактический статус перед оформлением отмены.

## Проверка состава при получении

Получатель сверяет количество пакетов и может сообщить сотруднику о видимом повреждении упаковки. Отсутствующий оплаченный товар обрабатывается по [правилам недовоза](delivery-policy.md). Фотография отсутствующего товара не требуется; в карточке сохраняют отметку о выдаче и результат сверки.

Проблема с качеством обнаруженного товара рассматривается по [порядку проверки повреждённых продуктов](damaged-products.md). Выдача пакетов не означает, что клиент отказался от последующего обращения в установленный срок.

## Заказ не выдан

Если приложение показывает выдачу, а клиент сообщает, что не получил пакеты, оператор проверяет время операции, использованный код и запись пункта. До выяснения результата он не отмечает недовоз отдельных товаров и не создаёт повторный возврат. Если невыдача подтверждена, регистрируется обращение по всему заказу и решение о возврате передаётся в платежи.
