# Порядок хранения охлаждённого заказа в пункте «Проспект»

Порядок действует для охлаждённых заказов самовывоза в пункте «Проспект». Начало хранения определяется уведомлением клиента о готовности. Этот порядок не меняет условия обычных пунктов выдачи.

## Срок хранения

Охлаждённый заказ в пункте «Проспект» хранится 90 минут после уведомления о готовности. По окончании срока сотрудник проверяет возможность дальнейшего хранения и записывает итог в карточку заказа. Продление не считается подтверждённым по одному обращению клиента.
