# Получение заказа в пункте самовывоза

Правила обычной выдачи заранее оплаченного продуктового заказа в пункте самовывоза. Клиент приходит после уведомления о готовности заказа.

## Получение по номеру телефона

Если код выдачи не открывается, сотрудник может выдать заказ самовывоза по номеру телефона в карточке заказа. Клиент показывает паспорт; паспорт обязателен при обычной выдаче заказа. Сотрудник сверяет телефон с карточкой и подтверждает выдачу.
