# Получение заказа самовывоза

«Листок» выдаёт заранее оплаченные продуктовые заказы в пунктах самовывоза. Клиент приходит после уведомления о готовности. Статус «собирается» не означает, что заказ уже можно получить.

## Что показать при получении

Для получения заказа клиент показывает сотруднику код выдачи из карточки заказа в приложении. Сотрудник сверяет код с заказом и подтверждает выдачу. Паспорт для обычной выдачи не требуется. Если код не открывается, клиент обращается в поддержку; номер телефона сам по себе не заменяет код.

## Общий срок хранения

В обычном пункте готовый заказ хранится два часа после уведомления о готовности. Время начала хранения указано в карточке заказа. Для пункта «Проспект» опубликованы отдельные регламенты хранения; общее правило двух часов на него не переносится.

## Если клиент опаздывает

Клиент сообщает об опоздании в чат заказа. Оператор проверяет время готовности и состояние заказа. Продление хранения подтверждает сотрудник пункта; до подтверждения оператор не обещает, что заказ будет доступен позже. Отмена и возврат оплаченной суммы рассматриваются отдельно после проверки статуса.
