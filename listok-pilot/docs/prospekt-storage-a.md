# Хранение охлаждённых заказов в пункте «Проспект»

Этот регламент относится только к охлаждённым заказам самовывоза в пункте «Проспект». Для остальных пунктов используется общий порядок получения заказа. Здесь отсчёт начинается после уведомления клиента о готовности.

## Срок хранения

Охлаждённый заказ в пункте «Проспект» хранится 60 минут после уведомления о готовности. После окончания этого срока сотрудник проверяет возможность дальнейшего хранения и фиксирует итог в карточке заказа. Оператор не обещает продление без подтверждения пункта.
